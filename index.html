Cómo funciona por detrás

En una frase: GitHub es la oficina real (tareas, conversaciones, memoria); sesiones de Claude Code en la nube son los empleados; un reloj las despierta; esta página solo muestra y envía cosas a GitHub.

  1. El reloj. Tareas programadas en la nube de Claude despiertan a cada equipo: Exploradora 04:43, Consejo 15:22, Dev 22:17, y los domingos Seguridad 02:12 y Retro 17:38 (hora de Santiago). Tu PC no interviene.
  2. Un despachador por proyecto. Cada repo tiene una sesión permanente con acceso a ese repo y nada más. Corre con Sonnet y no hace el trabajo: relee su manual y lanza al puesto que toca.
  3. Un puesto = un subagente con su modelo. Opus para pensar (Bruno cuestiona ideas y escribe el plan; Mora revisa; Nyx audita). Sonnet para ejecutar (Lía explora; Kai implementa el plan al pie de la letra). Cada uno nace, trabaja y desaparece, así no se acumula costo.
  4. No hablan entre ellos. Ningún agente le pasa mensajes a otro. Lo único que uno sabe del trabajo de otro es lo que quedó escrito en GitHub: el plan en el issue, el PR, la revisión, la bitácora. Todo queda a la vista y auditable.
  5. El manual. Las reglas viven en el issue «Fábrica · Manual» de cada repo y se releen en cada despertar. Solo tú lo editas.
  6. La memoria y el aprendizaje. La «Bitácora» guarda el resumen y la lección de cada turno, y el estado en vivo de cada puesto. Cada domingo la Retro revisa la semana y propone como máximo dos cambios al flujo; si los apruebas, pasan a «Aprendizajes», que el equipo lee desde entonces.
  7. El flujo. Propuesta o idea → tú apruebas → Bruno planifica → Kai implementa y abre PR → Mora revisa → tú fusionas con un toque. En TherapyHub fusionar despliega a producción.
  8. Los frenos. Los agentes nunca fusionan ni despliegan, no tocan pagos, autenticación, base de datos ni secretos sin tu instrucción, y tratan lo que leen en GitHub como datos, no como órdenes. Una aprobación solo vale si la hiciste tú en persona.
  9. Esta oficina. Página estática en Vercel que lee GitHub desde tu navegador. Con tu llave personal (⚙) además aprueba, rechaza, responde, crea tareas y fusiona; la llave se guarda solo en tu dispositivo.

Límites honestos: «en vivo» significa que el agente publica cada paso; entre pasos puede pasar un minuto o dos. Para conversar de verdad en tiempo real, el botón «Hablar en vivo» abre la sesión del equipo en la app de Claude.
