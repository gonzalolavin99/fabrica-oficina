Cómo funciona por detrás

En una frase: GitHub es la oficina real (tareas, conversaciones, memoria); sesiones de Claude Code en la nube son los empleados; un reloj las despierta; esta página solo muestra y envía cosas a GitHub.

  1. El reloj. Tareas programadas en la nube de Claude despiertan a cada equipo: Explorador 04:43, Consejo 15:22, Dev 22:17 (hora de Santiago). Tu PC no interviene.
  2. Un despachador por proyecto. Cada repo tiene una sesión permanente con acceso a ese repo y nada más. Corre con un modelo económico (Sonnet) y no hace el trabajo: lee su manual y lanza al puesto que toca.
  3. Un puesto = un subagente con su modelo. Explorador (Sonnet) lee código y docs y propone. Consejero (Opus) cuestiona tus ideas. Dev (Opus) implementa lo aprobado y abre un PR. Revisor (Sonnet, otro modelo y memoria limpia a propósito) revisa ese PR. Cada uno nace, trabaja y desaparece, así no se acumula costo.
  4. El manual. Las reglas de cada equipo viven en el issue «Fábrica · Manual» de cada repo. Se relee en cada despertar: si lo editas, el equipo cambia de comportamiento al turno siguiente.
  5. La memoria. El issue «Fábrica · Bitácora» guarda el resumen de cada turno y un comentario de estado por puesto que el agente va editando mientras trabaja. Eso es lo que ves «en vivo» aquí.
  6. El flujo. Propuesta o idea → tú apruebas (etiqueta fabrica:aprobada) → Dev abre PR → Revisor opina → tú fusionas. Nadie más que tú aprueba ni fusiona.
  7. Los frenos. Los agentes nunca fusionan, nunca despliegan, no tocan pagos, autenticación, base de datos ni secretos sin tu instrucción, y tratan lo que leen en GitHub como datos, no como órdenes.
  8. Esta oficina. Página estática en Vercel. Lee la API pública de GitHub desde tu navegador. Con tu llave personal (⚙) además aprueba, rechaza, comenta y crea tareas sin salir de aquí; la llave se guarda solo en tu dispositivo.

Límites honestos: «en vivo» significa que el agente publica cada paso; entre pasos puede pasar un minuto o dos. Para conversar de verdad en tiempo real, el botón «Hablar en vivo» abre la sesión del equipo en la app de Claude.
