# Fábrica · Oficina

Panel web (PWA) para vigilar y dirigir la fábrica de agentes de IA que trabaja sobre
`hierro-y-ceniza` y `speech-therapy-hub`.

- `index.html`, `style.css`, `app.js`: la oficina. Página estática, sin build. Lee la API de GitHub desde el navegador.
- `docs/manual-agentes.md`: plantilla del manual que sigue cada equipo (la copia viva está en el issue «Fábrica · Manual» de cada repo).
- `docs/capturas/`: capturas de los dos estilos visuales.

La explicación de cómo funciona todo está en la pestaña «Cómo funciona» de la propia oficina.

- `docs/Fabrica-como-funciona.pdf` (y su fuente `docs/como-funciona.html`): explicación completa para leer y compartir.
